## 📖 About The Project

**File Operator** is a lightweight, terminal-based **Personal Journal Manager** built with pure Python. No databases, no dependencies — just a simple `journal.txt` file that grows with your thoughts. Add entries, search them by keyword or date, view your whole journal, or wipe it clean when you need a fresh start.

## ✨ Features

<img align="right" width="350" src="https://user-images.githubusercontent.com/74038190/229223263-cf2f4ecc-e1c6-4c93-a2b0-8bd07a2ba7c3.gif">

- 📝 **Add Entry** — Save a timestamped journal entry instantly
- 📚 **View Entries** — Read back your full journal history
- 🔍 **Search Entry** — Find entries by keyword or date
- 🗑️ **Delete All Entries** — Clear your journal with a confirmation step
- 💾 **Persistent Storage** — Everything saved locally in `journal.txt`
- ⚡ **Zero Dependencies** — Runs with plain Python, no installs needed

## 🚀 Getting Started

### Prerequisites

```bash
python --version   # Requires Python 3.8 or higher
```

<div align="center">
<img src="https://user-images.githubusercontent.com/74038190/212284136-03988914-d899-44b4-b1d9-4eeccf656e44.gif" width="300">
</div>

### Installation

```bash
# Clone the repository
git clone https://github.com/niharsheladiya/File-operator-.git

# Move into the project directory
cd "File-operator-/File operator"

# Run the application
python "file operator.py"
```

---

## 🎮 Usage

Once you run the script, you'll be greeted with an interactive menu:

```
Welcome to Personal Journal Manager!
1. Add a New Entry
2. View All Entries
3. Search for an Entry
4. Delete All Entries
5. Exit
```

Simply enter the number of the action you want to perform, and follow the prompts. 🎉
